Test bench

A safe place to see CookieShield work before you trust it on real sites. Below are 59 small practice websites, each with a different kind of cookie pop-up: the big consent tools (OneTrust, Cookiebot and others), banners in 22 languages, tricky layouts, and trick banners that only offer “Accept”. Open any of them with CookieShield installed and watch Pip handle it. The same pages run in my automated tests.

1 · What to expect

Each card shows the expected result. ✓ Rejected banners should vanish within a second. ! Needs you ones must stay, with a note from Pip saying nothing was accepted.

2 · Check the proof

Click the Pip icon in your toolbar → What exactly happened? It shows which button was clicked and the consent record it read afterwards.

3 · Check the site still works

Scroll, sign in, send the contact form, use “About (SPA)” and “Next page”. Each page also says whether you’re signed in after a reload.

What “Reset demo cookies” does: like real sites, these practice pages remember your answer in a cookie, so once a banner is handled it won’t show again. The button clears those practice cookies (only for this test bench) so every banner appears fresh. To see “remember my choice” in action, reload a page after it has been handled instead: there’s no banner and the popup says Your “no” is remembered.
