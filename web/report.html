Report a site

A banner that wasn’t handled, a wrong choice, or a site that broke? The fastest way is the Report a problem button in the extension popup: it fills in the technical details for you. You can also use this form.

What happens to a report

It becomes an issue in the project’s GitHub repository, labelled site-report. A maintainer adds a rule to extension/rules/cmp-rules.json and a test page, and every installed copy that has rule updates switched on picks up the fix.

We keep only the site name (e.g. example.com, never the full address), the problem type and your comment. No IP address is stored.
