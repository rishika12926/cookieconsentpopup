Privacy policy

Last updated: October 2026. CookieShield is a Chrome extension that rejects optional cookies on cookie pop-ups. This page explains every piece of data it sends, and how to stop it.

The short version

  • Your history of handled sites, settings and site memory stay in your browser. They are never uploaded.
  • By default, CookieShield sends one anonymous summary of counts per day, with no website names and no identifier. You can switch it off.
  • Sharing which websites showed a cookie banner is off unless you switch it on.
  • Problem reports are sent only when you press “Report a problem” and choose to share.
  • Page translation runs on your computer with Chrome’s built-in translator. Page text is never sent anywhere.

Never collected

Full web addresses, page titles, search terms or query strings; your browsing history; cookies, sign-ins or tokens; page content or anything you type; persistent identifiers of you, your browser or your device. CookieShield does not need any of these to know whether it works.

How the data is stored and used

  • Data is stored only as daily totals in a database run by the CookieShield developer (Neon Postgres, hosted through Vercel). Individual summaries are added to the totals and not kept separately.
  • The servers don’t store IP addresses. To block abuse, an IP is hashed in memory for at most an hour and then forgotten. The hosting provider may keep standard request logs for a short time.
  • The data is used only to measure whether CookieShield works and to fix websites where it doesn’t. It is never sold, never used for advertising, and never shared with data brokers or anyone else, except where the law requires it.
  • Only the developer can see the totals, through a password-protected dashboard.

Your choices

  • Change either setting at any time in CookieShield → Dashboard → Settings → Privacy & data. There you can also see exactly what was sent.
  • Switching a setting off stops sending immediately, and anything collected but not yet sent is deleted from your browser.
  • Because nothing sent contains an identifier, data already sent can’t be traced back to you, so there is nothing to look up or delete for a specific person.
  • Uninstalling CookieShield deletes everything it stored in your browser.

Chrome Web Store Limited Use

The use of information received from the CookieShield extension adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements.
